# Examples

Each example runs live in the page from its style JSON, the same document `maplibre-demo` opens natively. Drag to pan, scroll to zoom, right-drag to rotate and tilt. They follow the [MapLibre GL JS examples](https://maplibre.org/maplibre-gl-js/docs/examples/); globe, terrain and the data layers come first.
