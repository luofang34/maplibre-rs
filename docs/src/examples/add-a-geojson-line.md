# Add a GeoJSON Line

An inline GeoJSON `LineString` over a vector basemap.

<div class="map-frame">
  <iframe src="./demo/index.html?style=./styles/add-a-geojson-line.json" title="Add a GeoJSON Line" allow="fullscreen" loading="lazy"></iframe>
</div>

Data: OpenFreeMap, OpenStreetMap. GL JS counterpart: [Add a GeoJSON Line](https://maplibre.org/maplibre-gl-js/docs/examples/add-a-geojson-line/).

## Run it natively

```bash
cargo run -p maplibre-demo -- headed --style docs/src/examples/demo/styles/add-a-geojson-line.json
```
