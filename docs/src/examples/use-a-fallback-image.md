# Use a Fallback Image

`coalesce` over `image` draws the first icon the sprite provides.

Data: OpenFreeMap, OpenStreetMap. GL JS counterpart: [Use a Fallback Image](https://maplibre.org/maplibre-gl-js/docs/examples/use-a-fallback-image/).

## Run it natively

```bash
cargo run -p maplibre-demo -- headed --style docs/src/examples/demo/styles/use-a-fallback-image.json
```
