# Introduction

maplibre-rs is a portable and performant map renderer written in Rust. It draws [MapLibre styles](https://maplibre.org/maplibre-style-spec/) with WebGPU on Linux, macOS, Windows, Android, iOS and in the browser, where it also runs on WebGL 2.

Vector, raster and terrain sources, a globe with atmosphere, 3D terrain and buildings, labels with collision detection, heatmaps and hillshading all come from the same style document MapLibre GL JS and MapLibre Native read. The [Examples](./examples/index.md) show them running.


## Name

The name of the library is "maplibre-rs". The camel-case version of it is "MapLibreRs".
